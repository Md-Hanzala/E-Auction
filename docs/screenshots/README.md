# HASHbid UI Screenshots

This directory is designated for project visual assets and walkthrough screenshots.

### Recommended Files:
- `01-homepage-hero.png`: Homepage hero section with the brand identity, dynamic featured live lot card, and architectural overview.
- `02-buyer-floor.png`: Active buyer bidding floor displaying live countdown timers, AJAX real-time bid values, and lot cards.
- `03-settlement-invoice.png`: Official settlement receipt modal with printable invoice stylesheet.
- `04-seller-console.png`: Merchant inventory console, product listing form with image upload preview, and dispatch details.
- `05-admin-dashboard.png`: Central operations supervision console, live floor monitor, product pricing approval, and seller verification queues.
- `06-bid-audit-ledger.png`: Chronological bid transaction audit log with quick in-DOM search filtering.

### Guidelines:
- Capture at standard desktop resolution (1920x1080 or 1440x900).
- Keep file sizes optimized using PNG or WebP format.
